How to make an easy logo

Keywords: Logo, Affinity, Software, Design, Brand

If you would like to be a designer or a creator, you need a software to make digital products and some knowledge about it. There are a lot of various application and software for creating logo. Logo, pictures or wireframe of website you can make by software Affinity by Canva. This software is free for now. There is needed to create a new account or you can sign in by your Canva account, if you have one. If you want to use AI technology, you have to have a subscription of Canva Pro.

Download, installation and start

Open this url address in your favourite browser. Click on Sign up to download. Write email where you get a confirm code. This code you put to a section on this website. You can Opt in on newsletter there. After login you can download Affinity software for various operating systems like Microsoft Windows (Intel/AMD, ARM) and Mac OS (Apple Silicon, Intel). Choose your operating system, download it and install.

You can test this software by Virus Total to know it is without viruses. If you do not experience with this online scanner, there is needed to open this website and upload downloaded software. Then wait a minute and a result displays there. If all list is in green colors, it is good. However, if there is a red color, there is a virus.

Two times click on installation file and a window will be opened. Click on Install and wait few seconds because there will be a window with Log in or sign up. Click on it and you will redirect to your favourite browser. Write your email address to a box on website you gave first. Then the Affinity software opens on your device and there will be a short video. You have to agree or do not agree with collecting your personal data. You can see introduction video (Watch tutorial) or to start to create Start creating. You can see a Home window with easy samples, short tutorials (it is needed to download first in section Welcome to Affinity). In the end there will be a window you can create like you see below.

A brand logo

Logo is the first project of every designer or creator. If you want to sell products with your brand you need the logo of your company. If you want to make a website, application or game, you need a nice and interesting logo. A size of logo is at least 500px x 500px. It depends how platform you make for.

Easy and nice logo is possible to create for few minutes with Tools. Spiral Tool is for creating shape and Artistic Text Tool for text in this tutorial.

Open new document by click on File and then New. There will be a window with two sections. On the left you choose a format of document and on the right a setting. Then click on Create document. A shape you make by Spiral Tool click on small arrow in left panel. There will be a lot of tools. Click on Spiral Tool and one more Spiral Tool. There will be created a easy spiral which is needed to paint. Click on Color on the right. By Set Foreground you paint outline and a pane by Set Background. You have to choose an image first you put. Then click on Color and Set. In the end click on a color in a big circle. Paint all what do you want and you can add a text to this logo. Click on Artistic Text Tool and one more. Paint the text same by Color. It is possible to choose a sort of script click to up panel. You can see, if you click on the text in logo.

It is possible to export this logo to various formats for example PNG. Click on File and Export. Choose a format from a list and click on Export.

Summary

You can make a nice logo by Affinity. If you want to make self shapes, you can use tools like Paint Brush Tool or Pen Tool.

Remember a part of image you want to adjust, you can choose to click on it. Then tools display for specific part of logo.

Famous software Adobe Illustrator contains a lot of similar tools with other options.

Affinity by Canva is free and it is good for beginners.
