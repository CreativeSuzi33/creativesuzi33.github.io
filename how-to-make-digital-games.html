How to make digital games

Keywords: game design, programming, editor, tools, environment

A game is part of humanity, people and environment long time. The games were played in a corporeal state most of time. Now the games are played on various digital devices. A lot of people who played some games they would like to make some games for self, friends or as professionals. This short tutorial is for these people.

Software and programming languages for development of digital games

Very important thing for a game development is a knowledge. There are mainly programming languages, software for the game development, and a design of game environment and figures. How software you can want to use you have to know same programming language. It is important, if you want to make the digital games for smartphones, computers or game consoles. For it is needed to adapt whole a game development.

It is same like to make various applications. You have to make up how software and programming language to use or how platform you would like to make the game for. You can think about figures and environment of your game. It is possible by software for drawing and making 3D figures and animations. A lot of these are possible to make by programming language and its framework and library or by software for making games like Unity, Unreal Engine, Roblox, Godot. It is good to know to use the advanced editors for programming like Visual Studio with its tools for development (Unity and C#, Unreal Engine and C++) or JetBrains Rider. Well-know software for making 3D objects is Blender. Paid software is mainly Adobe (Animate, Substance 3D, Photoshop, Illustrator) or Autodesk 3ds Max.
