How to start to program with my Theoria application

Keywords: Programming, Microsoft Windows, Apple, Linux, Android

Informatics is wide-ranging branch in general and main branch, if you want to became a programmer. It includes to learn various things.

Programming languages and technologies

What programming language you want to learn you have to choose technologies. The basic are same. First you have to learn basic of informatics as bit and byte, logic values and operations. You can choose programming language according to operating systems or according to what programming language or technology you prefer. There are a lot of operating systems in the world but the most famous are Apple OS (iOS, iPad OS, macOS, tvOS, visionOS, watchOS), Linux and MS Windows. For all of these are used various technologies and programming languages.

Microsoft Windows and programming

If you work or study on Microsoft Windows, probably you will prefer programming language for MS Windows as C# and .NET framework. You can create a game for you or for someone in Unity. You will have to learn all of this operating systems (OS) from a kernel to how the operating system and applications work. Microsoft has more tools for developers. The most well-known are Visual Studio (with various versions, free or paid) and Visual Studio Code. They are editors for coding. They have a lot of extensions and other tools for various programming languages and technologies. You can create websites, desktop or mobile applications or some easy applications which are used by command line (CMD) for servers. Many companies use OS MS Windows and its applications or software. If you decide for MS Windows you have to learn C# as programming language, object oriented programming (OOP) and .NET as foundations. Then you need to know other technologies, e. g. database (SQL), computer network system, encryption and safety. There is good to know the basic of HTML5, CSS3 and JavaScript for better understanding harder syntax of C#. Some people talk about it that is good to know for beginners but if you like to learn hard things maybe you will understand without it. However if you want to make websites you have to know this beginner knowledge. Developers often work with system which saves their work online on cloud, e. g. GitHub. It is free with big community. And community, there is good to know to choose technology with good support for beginning. They can advise or you can ask in some portals for developers like GeeksForGeeks or Stackoverflow.

Linux is for people who do not like Microsoft

There are people who have not liked MS Windows in the world. They have worked on Linux. There are many kinds of Linux operating systems with various distributions. The basic kernel is built on Linux and the rest of this operating system is mostly own OS. They divide for various specializations — for home, students, developers, employees, servers and companies. It means they are used according to its demands, from easy to hard. There is good to begin with easy Linux OS, if you are beginner in Linux. You can install this operating system to virtual machine and then learn and coding in it. Small Linux as Slax you can install to computer memory and work with it. I have never used it but I have worked with virtual machine (VirtualBox). There is one opportunity how work with Linux and Windows too. You can divide your hard disk to two and more parts and install two operating systems on one hard disk. It is for advanced users of MS Windows or Apple, according to what you use. For all software you have to think about that developers sometimes make software with viruses unfortunately. I have rich experiences with it. It is good every software you download from internet or buy on CD to scan online or in your operating system with virus scanner. One good online scanner is VirusTotal which includes about sixty various antiviruses. You can scan software or something digital to 650MB. People say that Linux is OK but I have experience that I have scanned it and sometimes there was a virus. It can be a small script which downloads your personal data from your computer to computer of hacker after installation or click on. Developers who work on Linux learn and work mainly with Bash, C or C++ programming language. There are many learning portals on the internet which learn programming languages, e. g. W3Schools or TutorialsPoint. You can find many information about what you are interested in.

Apple and its technologies

Apple is the most famous company in the USA, I think. It makes own operating systems and applications with large servis. It has iOS operating system for smartphones which manufactures too. It is same as MacBook (Pro, Air, Mini), watches and others. For these systems and devices is used own programming language. In the past it was Objective-C and in the present day it is Swift. There is often used Terminal in Mac OS. By it you can install missing packs for your operating system with Homebrew.

Android for masses

Android is the newest platform for smartphones which has a lot of customers. It is free as Linux and it is built on Linux. Certainly, Linux is not free always but you can install without paying. You can download for free for using, testing and learning. However if you want a device with Linux, you have to pay for it. Or if you want to use some software which was created on Linux you can pay too. It depends on company which the software offers for sale or not. SDK of Android you can instal free too and to create nice applications in two programming languages: Kotlin and Java. Kotlin is own programming language of Google and this company works on to use it. You can create the Android application by source code of C++ too. If you want to build an application you need a compiler. There are two opportunities in Android Studio (it is editor — IDE — for creating Android applications) how compile source code: Kotlin and Gradle. Second is built on Groovy programming language which has same syntax as Java but it is more easier. Other language you will use in Android is XML. It is for design part of Android application. SQLite is used in Android application as small and fast database. It is good to have own Android device to test your application but Android Studio has own virtual device which is built according to a real device. There are a lot of extensions and learning courses in Android Studio for creating own Android applications. Huawei has own regulated Android and you can create or install applications for Huawei device.

Publishing applications in stores or on website

Every platform has own conditions for publishing your application but you can prepare for paying some money for developer account. In Apple is about 100$/yearly, in Android is about 25$ once. You can decide to make applications according to your favourite hobbies. Or you would like to create website than application. Then you have to learn other programming languages, frameworks and libraries, servers and databases. There are a lot of various technologies for it. The most famous is WordPress for creating websites. It is built on PHP. So if you want to be a developer (not only clicker), you have to learn PHP at least. A lot of hostings offers WordPress in their services. To the category of PHP belongs Joomla too. There are some frameworks in PHP, e. g. Nette. Documentation of this framework is translated to various languages.

Making website and web applications

The basic of making website is to know HTML5, CSS3 and JavaScript. HTML is only hypertext markup language and CSS is Cascading Style Sheet. They are not programming languages. However JavaScript is scripting programming language. It is basic of many frameworks and libraries as: Ionic, React, Vue and others. For building website you need some tools as: Node and NPM. You will use Terminal, CMD, PowerShell or other software according to your operating system. You can use your favourite IDE for these tasks too. Many documentations for developing website you can find in Mozilla. For website maybe you would like to learn Ruby with its Ruby on Rails.

Programming for small devices

Other scripting programming language is Python which is used for various technologies. If you are interested in electronics maybe you would like to work with some cheap and small device as Raspberry Pi or Arduino. You can use for programming too. There are a lot of materials for learning, developing and creating. It is very interesting and you can learn many new things. If you create some software or application maybe you would like to upload it on the platform Source Forge or you can download your favourite software too. And check viruses!
